# Manifest VPN releases

Official desktop releases of [Manifest VPN](https://manifestvpn.com) for Windows and Linux.
iPhone, iPad and Mac: [App Store](https://apps.apple.com/app/id6835749358). Android: coming soon to Google Play.

Download the latest release from the [Releases](https://github.com/Manifest-LLC/manifestvpn-releases/releases/latest) page
or from [manifestvpn.com/download.html](https://manifestvpn.com/download.html). Both serve the same files; check them
against `SHA256SUMS` in each release.

| File | For |
|---|---|
| `ManifestVPN-<version>-build.<build>-x64-Setup.exe` | Windows 10/11, recommended installer |
| `ManifestVPN-<version>-build.<build>-x64.msi` | Windows, for IT deployment (Group Policy, Intune) |
| `ManifestVPN-<version>-build.<build>-x64-portable.zip` | Windows, no installer (extract first) |
| `manifestvpn_<version>+<build>_amd64.deb` | Debian, Ubuntu |
| `manifestvpn-<version>-build.<build>-linux-x86_64.tar.gz` | Other Linux distributions |

This repository holds release files and notes only; the source code is not public.
